鬼武者 Way of the Sword・ワールド

New Game Plusガイド

解放条件は1つだけ、そして失う予定の通貨が1つ、さらに引き継ぎリストは思っているより選択的です。New Game Plusとカルネージ難易度が実際に何をするのかを解説します。

翻訳について： このガイドは2026年9月4日の発売直後に判明した情報を、複数の独立した情報源で照合してまとめています。以下のリストは2つの詳しい英語版の情報源がほぼ一致した内容です。1点だけ一致していないのが衣装の引き継ぎです——ある情報源は「未確認」としており、別の情報源は同じ記事内で衣装を「引き継ぐ」リストと「リセットされる」リストの両方に載せてしまう内部矛盾を起こしています。どちらが正しいか判断せず、衣装の引き継ぎは本当に未確定として扱っています。また最高難易度の名称についても、英語版の複数の情報源は「Carnage」と伝えていますが、確認した日本語の個人ブログ1件は「鬼殺」と異なる名称を挙げていました——トロフィーガイドと同じく、断定せずカタカナ表記の「カルネージ」を暫定的に使用しています。

解放方法

ストーリーを1度クリアするだけです。それが唯一の条件で、特定のエンディングやサブコンテンツの完了、難易度の選択は必要ありません。エンドロールが流れると、New Game Plusとカルネージ難易度(ストーリー・アクションの上位に位置する最高難易度)の両方が解放されます。Story/Action/Carnageの全体像はトロフィーガイドと、カルネージがプラチナにとって重要な理由を参照してください。

引き継がれるもの vs リセットされるもの

引き継がれる

  • 能力——眼覚醒を含む、強化済みの基本能力・特殊能力
  • 鬼の力の覚醒——眼・腕・脚
  • お守りとその強化段階
  • 鬼灯袋とその強化段階
  • 鬼ノ武具——解放状態は維持される(強化段階は維持されない、右参照)
  • アイテムと供物
  • 幻魔手記(仮訳)の収集状況
  • 狛犬の救出状況
  • 再戦ボスの解放・クリア状況

リセットされる

  • 赤魂——ゼロに戻る。先に使い切っておくこと
  • 太刀・篭手の強化段階
  • 強化素材——絹布、玉鋼は再収集が必要
  • 鬼の弓——初期段階に戻る
  • 都の怪異(仮訳)の進行状況
  • 縁の依頼(仮訳)の進行状況
  • 破魔鏡の解放・アクセス状況
  • ストーリー・サブミッションの進行状況

鬼ノ武具については特に触れておく価値があります——New Game Plusに入っても全7種を解放済みの状態は維持されます(武器ガイド参照)が、個々の強化段階は他の装備と一緒にリセットされます。再び探しに行く必要はなく、強化をやり直すだけです。

始める前に

  • 持っている赤魂は全て使い切りましょう。 引き継がれないため、最終ミッションに向かう前に貯め込む理由はありません。
  • 気にかけているものは先に集め終えましょう。 幻魔手記(仮訳)・狛犬・縁の依頼(仮訳)は上記の通り達成状況が引き継がれますが、破魔鏡や都の怪異(仮訳)の進行状況は引き継がれません——優先順位は収集品ガイドを参照してください。
  • カルネージは本気の選択です。 New Game Plusの周回でカルネージを選ぶと、ストーリーとアクションのように気軽に易しい難易度へ戻ることはできません。

実践のポイント： カルネージでのNew Game Plusは「何もない状態から始める」周回というより「もう一度キャラクターを育て直すが、今度は速い」周回です——能力・お守り・鬼灯袋・収集の進行状況があるので完全にゼロからではありませんが、太刀と篭手の強さはリセットされるので、カルネージにいきなり無双状態で挑めるとは思わないでください。プラチナが目標ならトロフィーガイドのロードマップと合わせて計画しましょう。

よくある質問

New Game Plusはどう解放する？
ストーリーを1度クリアするだけです——他の条件はありません。

赤魂は引き継がれる？
いいえ——ゼロに戻ります。最終ミッションの前に使い切りましょう。

太刀・篭手の強化は引き継がれる？
いいえ——強化段階はリセットされますが、鬼ノ武具は解放済みの状態が維持されます。
